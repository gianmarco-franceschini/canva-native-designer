# Agenda aziendale

Applicazione web interna per gestire appuntamenti e riunioni, con assistente AI (Next.js, Supabase, n8n, Claude).

## Avvio

1. `npm install`
2. Copiare `.env.example` in `.env.local` e compilare le variabili.
3. `npm run dev` per l'ambiente di sviluppo.
4. `npm test` per eseguire i test.
